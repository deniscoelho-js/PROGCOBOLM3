# User COBOL Practice

## Projeto

1. Utilização da linguagem **COBOL** para o desenvolvimento de programas estruturados.
2. Praticar a organização do código em divisões: **IDENTIFICATION, ENVIRONMENT, DATA, PROCEDURE**.
3. Implementar programas simples para manipulação de dados e cálculos.
4. Exercitar boas práticas de programação estruturada.
5. Explorar entrada e saída de dados com `DISPLAY` e `ACCEPT`.
6. Documentar o projeto com comentários claros e objetivos.
7. Criar exemplos práticos para fixar lógica de repetição, validação e cálculos.
8. Desenvolver programas que simulam rotinas de processamento de dados em ambientes corporativos.
9. Aprender conceitos básicos de compilação e execução com GnuCOBOL.

## Funcionalidades

Práticas de programação em COBOL, incluindo manipulação de dados, cálculos simples, validação de entradas e exibição de resultados no console.

## Tecnologias

Este projeto foi desenvolvido utilizando as seguintes tecnologias:

- COBOL (GnuCOBOL - cobc)
- Terminal/Console
- Boas práticas de programação estruturada
